# EnglishCard - приложение для изучения английского языка

## Описание проекта
Это веб-приложение предназначено для изучения английских слов (перевод с русского языка на английский). 
Оно содержит как общие слова для всех пользователей, так и персональные слова для каждого пользователя. 

## Начало работы
1. Клонирование репозитория \
git clone <URL репозитория>


2. Создание виртуального окружения \
python -m venv venv \
source venv/bin/activate


3. Установка зависимостей \
   pip install -r requirements.txt


4. Настройка конфигурации. \
• Создайте файл .env в корне проекта \
• Добавьте параметры подключения к вашей БД: \
   HOST='localhost' \
   DATABASE='english_card' \
   USER='ваш логин' \
   PASSWORD='ваш пароль' \
   PORT='5432'


5. Запуск приложения \
• Откройте командную строку \
• Перейдите в папку с проектом \
• Выполните команду streamlit run main.py

## Структура проекта
• Авторизация пользователей \
• Викторина с множественным выбором (4 варианта ответа) \
• Добавление нового слова в словарь \
• Удаление слова из словаря \
• Статистика изучения слов \
• Просмотр схемы базы данных

## Технологии
• Язык программирования Python 3.12+ \
• СУБД PostgreSQL \
• Фреймворк Streamlit \
• psycopg2 для работы с PostgreSQL \
• Система контроля версий Git + GitHub \
• Среда разработки GigaIDE
